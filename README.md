# 🤖 AI Adoption & Workforce Impact Dashboard

## 📊 Project Overview
This Power BI dashboard analyzes the impact of AI adoption across industries focusing on:
- Automation Risk
- Salary Growth
- Workforce Skills
- Industry AI Readiness

## 🚀 Tools Used
- Power BI
- CSV
- Data Modeling
- DAX
- Data Visualization

## 📈 Key Insights
Industries with higher AI adoption and skilled workforce readiness show reduced automation risk, stronger salary growth, and improved long-term employment sustainability.
